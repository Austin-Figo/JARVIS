# JARVIS

Personal AI desktop assistant.

## Vision

JARVIS is designed to become a secure personal AI assistant capable of:

- Voice interaction
- Clap + wake phrase activation
- AI conversation
- Windows automation
- Application control
- File management
- Personal memory
- Task automation
- Android integration
- Messaging assistance
- Call assistance
- Secure permissions
- Standalone Windows application

## Wake Phrase

Daddy's home
